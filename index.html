    08 · Como uso agentes

    Como uso agentes.

    Aviso: a stack é muito modelável. O que está aqui é o recorte de hoje: a escolha muda conforme a tarefa e o escopo. Hermes Agent entra quando preciso criar bots integrados a ferramentas externas como Telegram e Discord; DeepSeek Harness, pelos plugins; Claude Code e Codex, pelos MCPs já integrados; OpenCode, por ser uma CLI no nível do Claude Code para código puro. O Traycer assume como orquestrador de tudo quando a tarefa é muito pesada.

    • Claude Code CLI e desktop

      Trabalho dentro do repositório com MCPs já integrados: leitura de código, edição e revisão na mesma sessão.

    • Codex Desktop

      Segunda opinião e execuções longas. Também com MCPs integrados, entra quando a tarefa pede escopo maior.

    • OpenCode CLI

      CLI no nível do Claude Code para código puro: edito, testo e fecho a tarefa sem sair do terminal.

    • DeepSeek Harness Desktop e web

      Fluxos montados peça por peça com os plugins do harness, no desktop ou no navegador.

    • Kimi Code CLI e desktop

      Entra quando preciso de contexto muito longo: leio repositórios grandes e fecho a tarefa numa sessão só, sem picar o trabalho em pedaços.

    • MiniMax Code CLI e desktop

      Onde este site foi revisado: sessões longas com memória entre turnos, skills e subagentes, do primeiro diagnóstico ao deploy.

    • Hermes Agent CLI e desktop

      Criação de bots refinados e integrados em ferramentas externas como Telegram e Discord, com memória, skills e subagentes.

    Orquestração. Traycer entra quando a tarefa é muito pesada: ele orquestra o trabalho entre Claude Code e Codex, que rodam também com modelos externos por um gateway de inferência, além dos modelos Claude e ChatGPT via opencodex.

    Desenho, orquestro e reviso.

    Projeto individual: desenhei a solução, orquestrei os agentes que a implementaram, revisei e mantenho o código. Publico os projetos direto do meu repositório e mantenho a documentação em português e inglês em dia.

    10 · Mentoria e contato

    Mentoria em agentes.

    Sessões práticas para você sair com um workflow de agentes rodando no seu projeto: escolher a ferramenta certa, montar o fluxo e revisar o que o agente entrega.

    • Escolha da stack Claude Code, Codex, OpenCode, Kimi Code, MiniMax Code, Hermes Agent e DeepSeek Harness: qual serve para cada tipo de tarefa, e quando o Traycer orquestra tudo.
    • Workflow de projeto Do desenho ao código revisado: MCPs, skills, plugins, memória e revisão humana em cada entrega.
    • Automação de tarefas Tarefas repetitivas viram rotina de agentes: coleta, análise, relatório e alerta, com você no controle.
    • Bots e subagentes Bots refinados integrados a ferramentas externas como Telegram e Discord, do rascunho à publicação.

    Sessões online e individuais para devs, estudantes e times pequenos: cada encontro termina com algo rodando no seu projeto. Também estou aberto a oportunidades em IA e agentes, dados, backend, cibersegurança e TI — remoto ou em Belém/PA.
