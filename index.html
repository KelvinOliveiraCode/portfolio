    08 · Como uso agentes

    Como uso agentes.

    Aviso: a stack é muito modelável. O que está aqui é o recorte de hoje: a escolha muda conforme a tarefa e o escopo. Hermes Agent entra quando preciso criar bots no nível do Grok bot; DeepSeek Harness, pelos plugins; Claude Code e Codex, pelos MCPs já integrados; OpenCode, por ser uma CLI no nível do Claude Code para código puro. O Traycer assume como orquestrador de tudo quando a tarefa é muito pesada.

    • Claude Code CLI e desktop

      Trabalho dentro do repositório com MCPs já integrados: leitura de código, edição e revisão na mesma sessão.

    • Codex Desktop

      Segunda opinião e execuções longas. Também com MCPs integrados, entra quando a tarefa pede escopo maior.

    • OpenCode CLI

      CLI no nível do Claude Code para código puro: edito, testo e fecho a tarefa sem sair do terminal.

    • DeepSeek Harness Desktop e web

      Fluxos montados peça por peça com os plugins do harness, no desktop ou no navegador.

    • Hermes Agent CLI e desktop

      Criação de bots no nível do Grok bot: memória, skills e subagentes, no terminal ou no desktop.

    Orquestração. Traycer entra quando a tarefa é muito pesada: ele orquestra o trabalho entre Claude Code e Codex, que rodam também com modelos externos por um gateway de inferência, além dos modelos Claude e ChatGPT via opencodex.

    10 · Mentoria e contato

    Mentoria em agentes.

    Ensino o caminho que percorro todo dia: escolher a ferramenta certa para cada tarefa, montar o fluxo e revisar o que o agente entrega. A ideia não é decorar prompts, é sair com um workflow rodando no seu próprio projeto.

    • Escolha da stack Claude Code, Codex, OpenCode, Hermes Agent e DeepSeek Harness: qual serve para cada tipo de tarefa, e quando o Traycer orquestra tudo.
    • Workflow de criação de projetos Do desenho ao código revisado: MCPs, skills, plugins, memória e revisão humana em cada entrega.
    • Automação de tarefas Tarefas repetitivas viram rotina de agentes: coleta, análise, relatório e alerta, com você no controle.
    • Bots e subagentes Criação de bots no nível do Grok bot com Hermes Agent, do primeiro rascunho à publicação.

    Sessões online e individuais, para devs, estudantes e times pequenos. Combinamos o formato pelo WhatsApp, e cada encontro termina com algo rodando no seu projeto, não com anotação no caderno.
