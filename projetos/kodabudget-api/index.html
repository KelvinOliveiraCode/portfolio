Assistente financeiro por voz

uma API que ouve, entende e responde por voz sobre as finanças do usuário.

Java·53 KB·2026·GitHub ↗

01 — O que foi entregue

Entregas nomeadas.

  • Transcrição local com Whisper — o áudio do usuário não depende de nuvem.

  • Tool calling com Spring AI responde só sobre os dados do usuário.

  • O modelo não inventa saldo: a resposta sai dos dados consultados, não da imaginação do LLM.

  • Ciclo completo por voz: pergunta falada, consulta e resposta falada.
